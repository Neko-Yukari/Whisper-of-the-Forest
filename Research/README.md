# Research — 可迁移的探索成果

这个目录把本项目的实验基础设施、结构化结果和结论从开发机搬进仓库，方便换机器继续。

先读 [HANDOFF.md](HANDOFF.md)，那里是完整交接（架构、参数、证据层级、未测项、复现步骤）。

| 路径 | 内容 |
| --- | --- |
| `HANDOFF.md` | 交接主文档 |
| `SOURCES.md` | 每个文件的来源映射（旧机路径 → 本仓库路径，含字节数与 SHA256）与**未上传清单** |
| `Tools/check-missiles/` | 射弹逻辑 harness（生产代码 + 引擎 shim）、分析程序、Def/语言/重构静态检查脚本 |
| `Tools/check-movement/` | 移动/装备相关校验项目与 IL 探针脚本 |
| `Tools/check-ui/` | UI 与本地化校验脚本、两个最小编译项目 |
| `Tools/check-elf/` | 精灵种族 DefInjected/语言注入检查脚本 |
| `Tools/evidence-driftcheck/` | 产物漂移检查项目文件 |
| `Results/` | a18 / a19 / a20 的结构化结果与事件流，加脱敏日志摘录、首飞录像 |
| `Graphify/` | 代码图谱重建脚本与原生切片清单（缓存与反编译源码不在此） |

## 边界

- 这里只有**本会话自己写的**代码与结果；游戏程序集、第三方模组源码、反编译输出、SDK、存档、完整日志一律不入库。
- 工具脚本沿用旧机器的绝对路径，未做改写（避免无意改动实验工具行为）；迁移时按 `Tools/README.md` 替换常量。
- 结果文件是原始 JSONL 的副本，未编辑、未裁剪；文本文件按仓库 `core.autocrlf` 规范为 LF 入库，与旧机原件的差异只在换行符（逐个验证过，见 `SOURCES.md`）。
