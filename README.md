# Whisper of the Forest

An Elf race and magic mod for **RimWorld 1.7** by Neko Yukari (`NekoYukari.WhisperOfTheForest`).  
适用于 **RimWorld 1.7** 的森林精灵种族与魔法模组（作者：Neko Yukari）。

---

## Requirements / 前置依赖

For **RimWorld 1.7** (per [About.xml](About/About.xml)):

- **Harmony** (`brrainz.harmony`)
- **Humanoid Alien Races** (`erdelf.HumanoidAlienRaces`)
- **RimLumen** (`NekoYukari.RimLumen`)
- **RimWorld - Royalty**
- **RimWorld - Biotech**
- **RimWorld - Anomaly** *(optional / 可选：启用 T2 反制灵能仪式等联动内容)*

---

## Installation / 安装方式

1. Download the latest archive from [**GitHub Releases**](https://github.com/Neko-Yukari/Whisper-of-the-Forest/releases).  
   前往 [**GitHub Releases**](https://github.com/Neko-Yukari/Whisper-of-the-Forest/releases) 下载最新版本压缩包。
2. Extract the `Whisper-of-the-Forest` folder into your RimWorld `Mods/` directory.  
   将解压后的 `Whisper-of-the-Forest` 文件夹放入 RimWorld 的 `Mods/` 目录。
3. Enable the mod after **Harmony**, **Humanoid Alien Races**, and **RimLumen** in the Mod Manager.  
   在游戏模组管理器中，将本模组排在 **Harmony**、**Humanoid Alien Races** 与 **RimLumen** 之后启用。
